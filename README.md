# 口播工作台 · 在线版

**正式网站：[aoengs.github.io/douyin-workbench](https://aoengs.github.io/douyin-workbench/)**

输入抖音博主主页链接，在网页中管理视频采集、口播识别和千问文案校验，逐条导出 TXT 与 SRT。

网页由 GitHub Pages 托管，视频下载、语音识别和文件保存由自己的电脑完成。使用时需要在同一台电脑上运行本机程序；只打开网站不会自动启动处理服务。

## 两个仓库的用途

| 仓库 | 可见性 | 内容 |
| --- | --- | --- |
| [douyin-workbench](https://github.com/aoengs/douyin-workbench)（本仓库） | 公开 | Pages 网页、样式和浏览器脚本 |
| [douyin-transcriber](https://github.com/aoengs/douyin-transcriber) | 私有 | 本机程序、启动脚本、完整安装说明和测试 |

本机程序只有获得授权的 GitHub 账号才能下载。若源码链接显示 404，请先登录已获授权的账号。仅下载本仓库不能运行视频识别。

## 第一次使用

目前面向 macOS，需要 Google Chrome 和 Python 3.12；推荐安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，由启动脚本安装运行环境。Windows/Linux 尚未验证。

1. 从私有源码仓库下载并解压本机程序。
2. 在终端进入解压后的程序目录，运行：

   ```sh
   zsh 启动在线版.command
   ```

   首次运行会创建 Python 虚拟环境并安装依赖；首次识别还需要下载语音模型。
3. 在自动打开的[本机连接页](http://127.0.0.1:8767/)复制“本次连接码”。
4. 打开[正式网站](https://aoengs.github.io/douyin-workbench/)，粘贴连接码，点击“连接工作台”。浏览器询问本地网络访问权限时，允许自己的工具页面连接本机。
5. 保持本机程序运行。连接成功后，可在顶部切换“文案提取”和“文案校验”。

连接码不是千问 API Key，不要把 API Key 填进连接框。连接码只保留在当前页面内存，刷新后需要重新连接；重启连接服务后旧码失效。断开网页或关闭网页不会停止已开始的任务，停止任务请使用工具中的“停止”按钮。

## 提取口播文案

1. 粘贴抖音博主主页链接、短链接或整段分享文字。
2. 设置提取数量：`0` 表示尝试收集全部，首次建议先试 `3` 条；需要保留 MP4 时勾选“同时保留视频”。
3. 开始提取。如果程序打开的独立 Chrome 要求抖音登录或验证，请手动完成。
4. 在任务列表查看进度、预览文案、下载 TXT/SRT 或导出文案包。可以暂停、停止和重试未完成内容。

识别使用本机 faster-whisper，不需要千问密钥。采集范围取决于当前登录状态下主页能够加载的作品，不保证获取全部历史视频。

## 配置千问文案校验

连接本机后，进入“文案校验”→“千问密钥配置”：

1. 填写自己的百炼 API Key 和 OpenAI 兼容接口地址，点击“保存到本机”；也可以直接选择百炼导出的密钥 CSV。
2. 使用工作空间专用密钥时，接口地址应与导出 CSV 中的 `openAiCompatible` 一致。
3. 先选一篇文案试用，检查“修改对照”和“待复核”内容，再决定是否批量校验。

**未配置密钥时不能发起文案校验。** 配置保存仅校验格式，实际调用还需要账户具备相应模型权限和可用额度。校验使用自己的百炼账户，按 API 用量计费。

校验只向百炼发送标题和字幕文字，不发送视频或音频。原始文案保留，SRT 序号和时间轴不变；不认可某处修改时，可选择“保留原文”。数字、名称和语义仍需对照原视频复核。

## 保存到移动硬盘

在本机程序目录中复制 `settings.example.json` 为 `settings.json`，将 `storage_root` 设置为移动硬盘的实际绝对路径。新任务使用新位置，已有任务保留原位置。完整目录说明见[本机程序 README](https://github.com/aoengs/douyin-transcriber#readme)。

硬盘断开时会停止保存，不会自动改存电脑内置磁盘。模型、登录配置和千问密钥保留在本机；文案与视频按本机设置保存。

## 隐私与连接

- 本仓库不包含 API Key、连接码、抖音登录状态、任务记录或视频。
- 千问密钥由本机程序保存，页面不回显，不写入浏览器存储。
- 本机连接服务只监听 `127.0.0.1:8767`，任务读取、修改和导出都需要连接码。
- 网页没有统计采集脚本；工具不会将密钥、任务内容或视频上传到 GitHub。访问网页本身由 GitHub Pages 提供服务。
- 请只在自己的工具页面使用连接码，不要分享给他人。

## 常见问题

**网页打开了，但提示“尚未连接本机”**

先运行 `zsh 启动在线版.command`，再复制本次连接码。网页和本机服务需运行在同一台电脑；在手机或另一台电脑打开网站，不能连接这台电脑的处理服务。

**无法连接或提示连接码错误**

确认本机连接页能打开，重新复制当前连接码，并检查浏览器是否允许该网站访问本地网络。刷新网页后需要重新配对。

**已连接，但不能校验文案**

在“文案校验”中配置自己的千问密钥，并确认账户权限、接口地址和额度。页面不显示已保存密钥的内容，只显示配置状态。

**关闭连接服务会怎样？**

网页会断开；已启动的提取或校验任务可能继续在本机运行。需要停止任务时，请先在工具中点击“停止”。

## 维护与部署

GitHub Pages 从本仓库 `main` 分支的根目录发布，入口为 `index.html`，`.nojekyll` 用于直接发布静态文件。

网页源文件由私有源码仓库中的 `pages/` 维护。修改提取、校验界面后，在私有源码目录运行：

```sh
.venv/bin/python build_pages.py
```

审核生成的 `pages/` 静态文件后同步到本仓库根目录；本 README 单独维护。不要同步整个本机程序目录，尤其不要上传 `data/`、`settings.json`、密钥 CSV、日志或媒体。更新上线后，应检查正式网址及本机连接。
